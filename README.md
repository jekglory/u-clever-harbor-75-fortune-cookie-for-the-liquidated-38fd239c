A single fortune-cookie message for a crypto trader who has just been liquidated — a real fortune that lands as a joke on the loss.

> Good fortune is coming your way. It was here yesterday, but you were busy being liquidated.

16 words, one line, plain text.

## Run it

```sh
python3 main.py
```

Prints exactly the fortune line, and writes the same line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python 3.13 standard library; deterministic — the same line on every run.
